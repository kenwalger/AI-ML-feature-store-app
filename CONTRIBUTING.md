# Contributing to AI/ML Feature Store

Thank you for your interest in contributing to the AI/ML Feature Store project!

## Development Setup

### Prerequisites

- Python 3.11+
- [uv](https://github.com/astral-sh/uv) package manager
- Node.js 18+ (for frontend)
- PostgreSQL 15+ with pgvector
- Redis

### Getting Started

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd "AI-ML Feature Store App"
   ```

2. **Install dependencies with uv**
   ```bash
   uv sync
   # Or using requirements.txt:
   uv pip install -r requirements.txt
   ```

3. **Set up environment variables**
   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

4. **Initialize database**
   ```bash
   python -c "from app.database import init_db; init_db()"
   ```

5. **Install frontend dependencies**
   ```bash
   cd frontend
   npm install
   cd ..
   ```

## Development Workflow

### Running Locally

**Backend:**
```bash
uvicorn app.main:app --reload
```

**Frontend:**
```bash
cd frontend && npm run dev
```

**Celery Worker:**
```bash
celery -A app.workers.celery_app worker --loglevel=info
```

### Code Style

- Follow PEP 8 for Python code
- Use type hints where possible
- Format code with `black` (if configured)
- Run linters before committing

### Testing

Run the test suite:
```bash
pytest tests/ -v
```

Run with coverage:
```bash
pytest tests/ -v --cov=app --cov-report=html
```

### Making Changes

1. Create a feature branch
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. Make your changes

3. Write or update tests

4. Ensure all tests pass
   ```bash
   pytest
   ```

5. Commit your changes
   ```bash
   git commit -m "Description of changes"
   ```

6. Push and create a pull request

## Project Structure

- `app/` - FastAPI application code
- `frontend/` - Vue.js frontend
- `tests/` - Test suite
- `scripts/` - Utility scripts

## Adding Dependencies

When adding new Python dependencies, use `uv`:

```bash
uv add package-name
```

This will update both `pyproject.toml` and `uv.lock`.

For development dependencies:
```bash
uv add --dev package-name
```

## API Changes

When modifying API endpoints:

1. Update endpoint documentation
2. Update OpenAPI schema (auto-generated by FastAPI)
3. Update frontend API client if needed
4. Add/update tests

## Frontend Changes

When modifying the frontend:

1. Follow Vue.js 3 Composition API patterns
2. Use Bootstrap 5 components
3. Update API service if endpoints change
4. Test in multiple browsers

## Questions?

Feel free to open an issue for questions or discussions about contributions.
