Fix static asset paths for frontend deployment

The frontend was building successfully but assets (JS/CSS) weren't loading
because of a path mismatch. Vite was building with base path '/' but FastAPI
serves static files from '/static'.

Fix:
- Configure Vite to use '/static/' as the base path
- Update FastAPI to properly mount the assets directory
- Assets will now be served from /static/assets/... matching the HTML references

The frontend should now load completely with all assets working correctly.
