Fix Bootstrap JS import in frontend build

The build was failing because Vite couldn't resolve the Bootstrap JS
import. Bootstrap JS was being imported in main.js but wasn't installed
as an npm package.

Fix:
- Remove Bootstrap JS import from main.js (not needed as npm package)
- Add Bootstrap JS via CDN script tag in index.html instead
- This matches the CSS approach (already using CDN) and avoids build issues

Bootstrap functionality will work the same way, but now the build will
succeed. The CDN approach is simpler and doesn't require bundling
Bootstrap JS through Vite.
