Fix frontend build by including dev dependencies

The build was failing because vite (a dev dependency) wasn't being
installed during the Heroku build process. Heroku sets NODE_ENV=production
by default, which skips dev dependencies, but we need them for the build.

Build Fix:
- Update heroku-postbuild script to use `npm install --include=dev`
- This ensures vite and other build tools are available during build
- Production build still only includes production dependencies in final output

The frontend will now build successfully on Heroku.
