Fix build warnings and integrate frontend serving

This commit addresses Heroku build warnings and sets up the frontend
to be built and served by FastAPI.

Build Configuration Fixes:
- Remove uv.lock file to eliminate package manager conflict warning
- Replace deprecated runtime.txt with .python-version (3.11)
- Remove uv-heroku-buildpack (using native Heroku Python buildpack)
- Add Node.js buildpack for frontend builds
- Add package.json for frontend build script

Frontend Integration:
- Configure FastAPI to serve static frontend files from app/static
- Add conditional root route: serves frontend if built, API info otherwise
- Update Vite config to output to app/static directory
- Update API client to use relative URLs in production
- Add release phase to build frontend during deployment

The app will now:
1. Build the Vue.js frontend during Heroku deployment (release phase)
2. Serve the frontend UI at the root route when built
3. Fall back to API info JSON if frontend isn't built
4. Serve API documentation at /docs and /redoc

This resolves the build warnings and enables the full-stack application
to work properly on Heroku.
