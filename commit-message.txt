Configure buildpacks explicitly for frontend build

The .buildpacks file wasn't being detected by Heroku, causing only
the Python buildpack to run and skipping the frontend build.

Buildpack Configuration:
- Set buildpacks explicitly via Heroku CLI
- Node.js buildpack runs first to build frontend
- Python buildpack runs second for backend dependencies
- heroku-postbuild script builds Vue.js frontend automatically

The buildpacks are now configured as:
1. heroku/nodejs (builds frontend)
2. heroku/python (installs Python dependencies)

On the next deployment, the frontend will be built automatically
during the Node.js buildpack phase via the heroku-postbuild script,
and the built files will be served by FastAPI at the root route.
